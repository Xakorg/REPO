# **App Name**: Xakteir

## Core Features:

- User Account & Email: User sign-up, login, profile management, and automatic assignment of a unique @mail.xakteir.com email alias.
- Basic Mail Interface: A minimal user interface for composing and sending emails, supporting both internal Xakteir addresses and external domains (though external delivery might land in spam folders).
- AI Web Search Tool: An integrated search bar leveraging an AI tool to efficiently explore the web and return relevant results, as highlighted in 'Search the web with AI...'.
- Xak AI Chat Assistant: An interactive conversational AI tool for users to ask questions and receive intelligent responses.
- Xakteir Dashboard: A personalized homepage providing 'Quick Links' to key modules (Games, XakView, Chat, News), displaying 'Latest News,' and featuring dynamic content like 'Riddle of the Day' and 'Joke of the Day'.
- XakView Basic Playback: A foundational module for displaying and playing pre-uploaded user-generated videos, fulfilling the 'YouTube-like' viewing experience for XakView content.

## Style Guidelines:

- Dark scheme with a primary deep violet (H=270) to evoke a futuristic and sophisticated atmosphere. Primary accent: #8433F3 (HSL: 270, 80%, 60%).
- Background color: A muted, desaturated version of the primary hue for consistency, #2A1F30 (HSL: 270, 20%, 15%).
- Accent color: A vibrant blue, analogous to the primary, for interactive elements and highlights, #48f226 (HSL: 240, 70%, 50%).
- The main font for both headlines and body text will be 'Inter', a grotesque sans-serif providing a modern, objective, and neutral aesthetic suitable for a versatile platform.
- Use minimalist, outline-style glyph icons for quick links and navigation items, maintaining clarity and consistency across all modules.
- Adopt a modular, card-based layout for dashboards and content display, enabling a clean and organized presentation of diverse information and applications.
- Incorporate subtle hover and click animations for buttons and quick links, enhancing user feedback and interface responsiveness without distraction.
